# Hey Buddy

Hey Buddy is a private Android assistant that helps fill forms using your own documents
(Aadhaar, PAN, driving licence, photo, signature, certificates). Everything stays on the phone:
the app has no internet permission, and documents are stored in an encrypted vault that opens
only with your fingerprint, face or PIN. Hey Buddy suggests and fills values, but you always
review them and press Submit yourself.

**Status:** Phase 1, Task 1.1 done.
